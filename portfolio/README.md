# Portfolio — Emmanuel Maziku

This folder contains a starter static portfolio for Emmanuel Maziku.

Structure:
- index.html — main portfolio page
- css/style.css — styles
- js/main.js — frontend scripts
- assets/ — images and media (add profile.jpg here)
- data/ — optional JSON data for projects

How to preview:
1. Open `portfolio/index.html` in a browser for a quick preview.
2. For a local static server: `python -m http.server --directory portfolio 8000` then open http://localhost:8000
